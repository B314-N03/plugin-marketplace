# AI Briefing Source Strategy

## Primary Search Queries

Run these searches in parallel to cover the landscape. Always append a time qualifier like "2025" or "this week" or "March 2025" based on the current date.

### Core queries (always run)

1. `"AI tools" OR "AI features" new launch site:techcrunch.com OR site:theverge.com OR site:arstechnica.com`
2. `Claude OR ChatGPT OR Gemini OR Copilot new features update`
3. `new AI developer tools 2025`
4. `AI model release announcement`

### Focused queries (pick based on user interest or run all)

5. `AI coding assistant new features` (dev tools focus)
6. `open source AI model release` (OSS focus)
7. `AI API new features developer` (API/platform focus)
8. `AI agent framework tool launch` (agents focus)

### Claude Code Skills queries (always run)

9. `Claude Code new slash command skill Anthropic site:anthropic.com OR site:docs.anthropic.com`
10. `"Claude Code" skills marketplace trending community`
11. `site:github.com "claude-code" skills OR "SKILL.md" new`

## Evaluation Criteria

When deciding what to include in the briefing:

- **Relevance**: Prioritize things the user can actually use or that affect their workflow
- **Recency**: Focus on the last 2-4 weeks unless user specifies otherwise
- **Significance**: Skip minor patch notes; include feature launches, new tools, model releases, pricing changes, paradigm shifts
- **Verification**: Cross-reference claims across multiple sources when possible
